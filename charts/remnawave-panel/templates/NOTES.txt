  1. Open the panel URL and log in with your initial credentials
  2. Add nodes: Nodes → Add Node → configure NODE_PORT and secret key on each node
  3. Create users and configure subscriptions

If subscription-page is deployed separately, set REMNAWAVE_PANEL_URL to this panel's URL
and generate an API token in: Settings → API Tokens.
